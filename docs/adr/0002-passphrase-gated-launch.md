# ADR-0002: 合言葉による限定公開から始める

- ステータス：採用
- 日付：2026-10-17

## 背景

静的サイトのホスティングは、次のような悪用を受けやすい。

- フィッシングサイト（銀行やログイン画面の偽物）
- マルウェアの配布
- その結果、ドメインが Google Safe Browsing などで危険と判定され、全サイトに警告が出る。最悪の場合、AWS アカウントが停止される

ログイン必須にすれば悪用は減るが、使い捨てアカウントで回避されるため、なくなりはしない。

## 決定

- 最初のリリースは **合言葉による限定公開** とする
- 合言葉は **サーバー側で検証** し、セッション（Cookie）を発行する。アップロード API はセッションがある場合のみ受け付ける
- 合言葉が必要なのは **アップロード画面のみ**。共有 URL は誰でも閲覧できる
- 以下の悪用対策が揃ったら一般公開する
  - ユーザーサイトを本体と別ドメインで配信する
  - 短い有効期限（1時間、設定値で変更可能）
  - 容量・ファイル数の制限
  - ファイル種別の制限
  - 一時公開サイトであることを示す表示
  - レート制限、WAF
  - 通報フォームと即時削除

## 理由

- 自分とメンバーが使える状態を早く作れる
- 悪用対策を1つずつ実装・検証してから一般公開できる
- 悪用はアップロードできる人がいて初めて起きるので、入口を締めれば閲覧を開いていても問題になりにくい

## 影響

- 合言葉の受け渡しは手動（メンバーに直接伝える）
- 一般公開の判断基準が、上記の対策リストとして明確になる
