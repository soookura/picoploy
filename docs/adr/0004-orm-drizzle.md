# ADR-0004: ORM は Drizzle を使う

- ステータス：採用
- 日付：2026-10-17

## 背景

PostgreSQL を TypeScript から扱う ORM として、Prisma と Drizzle を比較した。

| | Prisma | Drizzle |
|---|---|---|
| スキーマ定義 | 独自のスキーマ言語（`schema.prisma`） | TypeScript のコード |
| クエリ | 抽象度が高い（ネストした書き込みなど） | SQL に近い書き方 |
| トランザクション | ネストした書き込みで暗黙的に扱える | 自分で明示的に書く |
| マイグレーション | SQL ファイルを生成して適用 | SQL ファイルを生成して適用 |

社内の別チームでは Prisma を採用しているが、自分は使ったことがない。

## 決定

ORM は **Drizzle** を使う。

## 理由

- 学びたいことに SQL、トランザクション、インデックスが含まれる。Drizzle は SQL が透けて見えるので、これらの基礎が自然に身につく
- Prisma 固有の知識（スキーマ言語、クライアント生成、ネストした書き込みなど）は、Prisma 以外では役立ちにくい
- SQL の基礎が身についていれば、Prisma が必要になっても短期間で適応できる
- 「抽象度が高い ORM」と「SQL に近い ORM」の違いを理解し、説明できるようになる

## 影響

- トランザクションや関連データの取得を自分で書く必要がある（学習対象として歓迎）
- マイグレーションの運用（本番での適用方法、ブルーグリーンデプロイ時の expand/contract、ロック時間）は ORM と独立した課題として、フェーズ2以降で扱う
